# 花艺师培训 - 花束绑扎模拟

基于 Three.js + cannon-es 的花艺师培训 3D 物理模拟系统。包含取花茎、插花花泥、绑扎丝带、包装纸折叠四个阶段，支持四维实训评分与成绩档案回溯。

---

## 功能特性

### 核心玩法
- **取花茎阶段**：从料架拾取花茎，拖动插入锥形花泥
- **绑扎丝带阶段**：调节绑扎力度，过松散落、过紧折断
- **包装纸阶段**：自动播放包装纸折叠动画
- **移动端支持**：单指旋转、双指缩放

### 评分系统（四维）
| 维度 | 权重 | 说明 |
|------|------|------|
| 插花均匀度 | 30% | 基于花茎插入角度分布的均匀程度 |
| 绑扎力度 | 35% | 最终力度落在最佳区间的程度，折断/散落扣分 |
| 花材数量 | 20% | 插满 8 支满分，3 支起步 |
| 完成时间 | 15% | 45 秒内满分，180 秒保底 40 分 |

### 评级标准
| 评级 | 分数区间 |
|------|----------|
| S | ≥ 90 分 |
| A | 80 - 89 分 |
| B | 70 - 79 分 |
| C | 60 - 69 分 |
| D | < 60 分 |

### 成绩档案
- localStorage 持久化存储最近 20 条记录
- 按总分排行展示 Top 10
- 每条记录含时间戳、评级、总分
- 结算后自动归档

| 操作 | 方式 |
|------|------|
| 取花茎 | 点击料架上的花茎 |
| 拾花茎 | 点击地上的花茎 |

## 验收清单

### 第一阶段：取花茎 & 插花

- [ ] 点击料架上任意位置的花茎均可拾取（上排下排都可）
- [ ] 花茎被拾取后跟随鼠标/手指移动
- [ ] 拖动花茎移动时，视角不会随之旋转（OrbitControls 禁用）
- [ ] 拖到花泥上方释放，花茎插入花泥
- [ ] 掉落到地上的花茎可以点击拾起，重新插入
- [ ] 花茎掉落不会立即消失（y < -20 才清理）
- [ ] 顶栏评分面板实时显示：均匀度、花材数量、预估总分

### 第二阶段：绑扎丝带

- [ ] 插满 3 支以上花茎，"绑扎丝带"按钮启用
- [ ] 点击"绑扎丝带"进入第二阶段
- [ ] 可通过 W/S 或 ↑/↓ 调节绑扎力度
- [ ] 力度 < 8N 时显示黄色预警
- [ ] 力度 > 28N 时显示红色预警
- [ ] 力度在 12-20N 区间显示绿色（最佳）
- [ ] 绑扎过松（< 8N）触发散落效果，花茎四散
- [ ] 绑扎过紧（> 28N）触发花茎折断
- [ ] 顶栏绑扎力度得分实时变化

### 第三阶段：包装纸折叠

- [ ] 点击"包装纸"或"下一阶段"进入第三阶段
- [ ] 包装纸自动播放折叠动画（约 1.5 秒）
- [ ] 动画完成后弹出结算面板
- [ ] 结算面板显示 S/A/B/C/D 评级
- [ ] 结算面板显示四项维度得分明细
- [ ] 结算面板显示花茎数、折断数、用时
- [ ] 结算后自动保存到成绩档案
- [ ] 右下角成绩排行更新

### 成绩档案回溯

- [ ] 右下角显示成绩排行榜（Top 10）
- [ ] 每条记录显示排名、等级徽章、分数、日期
- [ ] 前三名有金银铜配色
- [ ] 刷新页面后历史记录依然存在
- [ ] 最多保留 20 条记录
- [ ] 结算后新记录自动插入排行

### 重置功能

- [ ] 点击"重置"按钮或按 R 键可重置
- [ ] 重置后花茎恢复到料架初始状态
- [ ] 重置后评分清零
- [ ] 重置后结算面板关闭
- [ ] 历史成绩不会被重置清除

### 页面交互

- [ ] 页面固定，不会意外滚动或缩放
- [ ] 移动端禁止双指缩放页面
- [ ] 禁止长按选中文本
- [ ] UI 面板有半透明毛玻璃效果
- [ ] 响应式布局，移动端适配

### 性能

- [ ] 桌面端最多支持 50 个刚体
- [ ] 移动端最多支持 25 个刚体
- [ ] 性能下降时自动降级质量
- [ ] 连续快速点击有防重复结算机制（800ms 冷却）

## 常见问题

**Q: 花茎点不到怎么办？**
A: 确保点击的是花茎本身（绿色圆柱部分），而不是插槽或料架背板。上排花茎也可以直接点击。

**Q: 怎样才能拿到 S 级评价？**
A: 需要：插满 8 支花、均匀分布、绑扎力度落在最佳区间（12-20N）、无折断无散落、45 秒内完成。

**Q: 历史记录存在哪里？会丢失吗？**
A: 存在浏览器 localStorage 中。清除浏览器数据会丢失，但重置游戏不会清除历史记录。
